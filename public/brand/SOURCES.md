# WikiToon brand assets

Made for WikiToon on 2026-09-27 from the project owner's logo concept (a TV with antennas and the
"WikiToon" lettering with eyes in the double "O"). The owner's original artwork includes
third-party characters and channel logos, so it is not used anywhere in the site; these assets
keep its idea, colors and lettering style without any third-party material.

| File | Use |
|---|---|
| `wikitoon-wordmark.svg` | Main logo: site header and footer. |
| `wikitoon-mark.svg` | TV symbol; same drawing as `src/app/icon.svg`. |
| `og.png` | 1200x630 link preview image (Open Graph and Twitter) for every page except series, which use their poster. |
| `src/app/icon.svg`, `src/app/favicon.ico` (16, 32, 48 px), `src/app/apple-icon.png` (180 px) | Favicons, rendered from the TV symbol. |

- Lettering: [Luckiest Guy](https://fonts.google.com/specimen/Luckiest+Guy) by Astigmatic,
  Apache License 2.0, converted to outlines, so the font file is not shipped.
- Everything else (TV, eyes, colors, layout) is original to WikiToon.
- Colors: yellow `#FFC21A`, teal `#22B7CA`, orange `#F7931E`, ink `#141414`.
